# Тестовая конфигурация «ТестовоеХранилище»

Исходная конфигурация корпуса `example/crs/`: из неё стенд `example/tools/crs/stand.mjs` собирает
хранилище на `crserver`, на котором скрипты `example/tools/crs/capture-*.mjs` снимают трафик и вывод
платформы. Выгрузка в XML, формат 2.21 (платформа 8.5.1).

## Происхождение

Перенесена байт-в-байт из проекта
[vscode-1c-repository-tools](https://github.com/iljyxa/vscode-1c-repository-tools) (коммит
`96ccb9e398bbd74ebaf75a9f769bd5ec0fc8f91e`, каталог `fixtures/config`). Там она написана с нуля:
минимальные файлы приняты `ibcmd`, затем платформа выгрузила их обратно (`ibcmd infobase config
export`), а объекты «по виду» (`Тест<Вид>`, по одному объекту каждого вида выгрузки) дописаны скриптом
`fixtures/tools/extend-test-config.mjs` того же проекта, который тоже грузит заготовки в базу и
выгружает их платформой. В каталоге лежит нормализованный платформой XML.

Корпус `example/crs/8.5.1/` снят именно с этой конфигурации: состав объектов определяет uuid, classID и
счётчики в снятых кадрах.

## Состав

| Объект | Зачем |
|---|---|
| `Catalog.Контрагенты` | справочник с реквизитом `ИНН`, модулем объекта, формой и макетом — объект с дочерними элементами и файлами разных видов |
| `Catalog.Контрагенты.Form.ФормаЭлемента` | управляемая форма с модулем формы |
| `Catalog.Контрагенты.Template.Реквизиты` | макет `SpreadsheetDocument` |
| `Catalog.Номенклатура` | простой справочник без модулей — объект без файлов кода |
| `CommonModule.ОбщегоНазначения` | общий модуль |
| `Subsystem.Справочники` | подсистема |
| `Role.Администратор`, `Language.Русский` | обязательный минимум |
| `Тест<Вид>` (`ТестConstant`, `ТестDocument`, `ТестInformationRegister` …) | по одному объекту каждого вида выгрузки (46 вместе с общим модулем `ОбработчикиСобытий` для подписки на событие и регламентного задания); заготовки минимальны — ровно то, что платформа требует для корректности вида |
| `Subsystem.Родитель` → `Вложенная` → `Глубокая` | подсистемы, вложенные на два уровня: путь `Subsystems/А/Subsystems/Б/Subsystems/В.xml` |

## Правки — только через платформу

Файлы не правятся руками: изменение состава — загрузка в базу (`ibcmd infobase config import`),
правка там и повторная выгрузка платформой. После изменения конфигурации корпус `example/crs/8.5.1/`
пересобирается скриптами съёмки целиком, иначе кадры и конфигурация разойдутся.

## Проверка

```bash
ibcmd infobase create --db-path=<пустой каталог> --import=example/crs/config
```

Платформа 8.5.1 создаёт базу и загружает конфигурацию без ошибок.
