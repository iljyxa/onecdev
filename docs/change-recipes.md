# Рецепты изменений — какие файлы трогать

Индекс справочника для `architect`, `reviewer`, `documenter` и сессии, которая сама планирует задачу. Рецепты
разложены по тематическим файлам в [`recipes/`](./recipes/): **читай только файл своего сценария**, а не все
рецепты подряд (целиком справочник — около 60 КБ, это ~18 тыс. токенов в контексте на всю работу агента).
Архитектурные правила, запреты и центральные контракты — в [`CLAUDE.md`](../CLAUDE.md).

Для каждого сценария указано, какие файлы трогать. Если требуется править сверх списка — задача решается в другом слое.

| Файл | Сценарии |
|---|---|
| [metadata-types.md](./recipes/metadata-types.md) | Новый тип метаданных; слот модуля (`ModuleSlot`); дочерний тег (`ChildTag`); контейнерный дочерний тип (ТЧ→Колонка, HTTPСервис→URLШаблон→Метод). |
| [properties.md](./recipes/properties.md) | Схема свойств / ключ панели свойств; свойство-ссылка на форму; состав свойств типизированного поля. |
| [xml-format.md](./recipes/xml-format.md) | Нумерация `id` формы; правило валидации формата; порядок `<ChildObjects>`; порядок `<Properties>` корня; вспомогательный XML-файл объекта; любой писатель файла выгрузки. |
| [ui-commands.md](./recipes/ui-commands.md) | Команда; потребитель пути формы; builder и декорация узла; view/webview; сервис инфры; возможность LSP; настройка; watcher; открытие BSL-модулей. |
| [database.md](./recipes/database.md) | Внешняя интеграция (vrunner); чтение данных из базы пакетным Конфигуратором; обмен с базой через CF/CFE-файл; операция Конфигуратора под `ConfigurationOperationGuard`. |
| [repository.md](./recipes/repository.md) | Операция хранилища, меняющая файлы проекта; источник статусов захвата; метод протокола crs; интеграционный тест с crserver; панель «История хранилища». |
| [mcp-server.md](./recipes/mcp-server.md) | Жизненный цикл и безопасность MCP-сервера (порт, идентичность, shutdown, Host/Origin). |
| [git-panels.md](./recipes/git-panels.md) | Часть объекта в панели «Изменения метаданных»; git-мутация над панелью; триггер обновления по git-событию; блок «История». |
| [refactoring.md](./recipes/refactoring.md) | Декомпозиция God-класса; перенос функции из 1С-скилов в расширение. |

Новый сценарий добавляется в подходящий тематический файл, а строка таблицы выше дополняется его названием.
