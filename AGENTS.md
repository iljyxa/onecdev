# Инструкции для Codex

Перед началом работы прочитай `CLAUDE.md` в корне репозитория и следуй общим правилам проекта. В нём описаны архитектура, порядок тестирования и работы с Git, а также ссылки на профильную документацию.

Соответствия команд Claude Code и навыков Codex перечислены в разделе «Codex» в `README.md`. Для полного конвейера используй `$pipeline`, для отдельной стадии — соответствующий навык. Общий протокол стадий — в `docs/agentic-pipeline.md`. Для проверки изменений используй npm-команды проекта и `bash .claude/scripts/qa-gate.sh`.

При делегировании используй роль из `.codex/agents/`. Если интерфейс запуска принимает только бриф, передай инструкции из TOML в брифе и укажи, какую стадию выполнить. Передавай ТЗ, базу сравнения, путь к плану или сводку QA по необходимости.

Сверяй правки субагента с состоянием до запуска. `architect` правит только план в `docs/plans/`, `documenter` — `docs/`, `CLAUDE.md` и `README.md`, `qa-e2e` — только тесты и E2E-фикстуры, `implementer` — файлы своего этапа. `reviewer` работает в режиме чтения. В совместном рабочем каталоге запускай этапы с пересекающимися правками последовательно. При нарушении границ разберись с правками субагента, сохранив правки пользователя.
