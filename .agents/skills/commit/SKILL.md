Возьми список файлов и сообщение или контекст из запроса. Прочитай «Git-процесс» в `CLAUDE.md`. Если файлы не выбраны, сначала согласуй список. Проверь текущую ветку, `git status --short`, индекс и дифф выбранных путей. Запрет проекта на коммит прямо в `main` сохраняется.

Для рантайм-изменений выполни `npm run compile` и `npm run lint`. При ошибке останови коммит и сообщи результат. Для нерантайм-изменений укажи, если проверки пропущены.

Покажи пользователю список путей и проект сообщения на русском. Включай только явно выбранные пути, исключая личные настройки. Если индекс содержит чужие staged-изменения, сохрани их и коммить только выбранные пути. При частично индексированном выбранном файле сохрани выбранный набор изменений. Соблюдай правила проекта для сообщения и запускай git-хуки. Действие ограничено локальным коммитом в текущей ветке задачи.
