---
name: sanity
description: Проверить компиляцию, линтер, сборку и архитектурные инварианты onecdev без запуска тестов.
---

Выполни команды из раздела «Sanity-чек после изменений» в `docs/project-rules.md`: compile, lint, build и восемь поисковых проверок. Для `rg` код 1 означает PASS, код 0 — FAIL с совпадениями, код от 2 — FAIL с ошибкой инструмента. Верни результат каждой проверки и места нарушений. Работай в режиме проверок, без исправления найденных нарушений.
